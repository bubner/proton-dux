# Proton VPN (Dux Shell)
This plugin controls [Proton VPN](https://protonvpn.com/) (through the [official command line binary](https://github.com/ProtonVPN/proton-vpn-cli)) from a [Dux Shell](https://duxlabs.dev/) plugin.

## Development
Use steps from https://duxlabs.dev/docs/dms/plugin-development to set up for development.
